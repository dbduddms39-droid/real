# Still September

Apple 원본 앱 아이콘을 사용하는 아이폰 스타일의 반응형 웹 UI입니다. 모바일에서는 화면 전체를 사용하고, 데스크톱에서는 기기 프레임을 표시합니다. 모바일 디자인 기준 폭은 390px이며, 특정 기종 대신 360~430px의 화면 폭과 사용 가능한 높이·안전 영역에 맞춰 아이콘과 여백을 조절합니다. 작은 화면도 대응합니다. 외부 라이브러리나 빌드 과정 없이 실행됩니다.

## 실행

```sh
python3 serve.py
```

Windows에서는 `py serve.py`를 사용합니다. 이 명령을 실행한 PC 브라우저에서 `http://localhost:8000`을 엽니다. 파일 수정 시 자동 새로고침됩니다. VS Code의 작업 실행 메뉴에서도 실행할 수 있습니다.

## 체험할 수 있는 기능

- Apple 공식 PNG 아이콘 26개, 첫 화면 16개 앱, 위젯, 4열 그리드, 반투명 독
- 캘린더 날짜와 시계 바늘은 실시간 표시, 다크·투명 모양은 원본 윤곽을 유지한 웹 색상 변환
- 홈 빈 공간 길게 누르기 또는 설정 → 홈 화면 사용자화: 라이트·다크·투명 모양, 작은·큰 아이콘 전환
- 홈 화면 2페이지: 가로 스와이프, 페이지 버튼, 키보드 방향키로 전환
- 메모: 브라우저 로컬 저장, 계산기: 사칙연산·백분율·부호 전환
- 캘린더와 시계: 기기 날짜·시간 표시, 사진: 갤러리·추억 카드·원본 보기
- 미리 알림: 현재 화면 내 할 일 추가·완료 표시, 전화: 번호 입력 데모
- 제어 센터: 우측 상단 누르기 또는 아래로 스와이프
- 잠금 화면: 제어 센터에서 전원 버튼, 위로 스와이프 또는 버튼으로 해제

날씨·연결·손전등은 예시 또는 시뮬레이션이며 실제 기기의 OS 기능은 제어하지 않습니다. 미구현 앱은 미리보기로 표시합니다. 메모는 브라우저와 사이트 주소마다 별도로 저장됩니다.

## 단일 파일과 배포용 ZIP

```sh
python3 export.py
```

`exports/`에 브라우저로 열 수 있는 `my-phone.html`, 정적 호스팅용 `my-phone-site.zip`, 전체 소스 `my-phone-project.zip`이 생성됩니다. HTML 파일은 모든 UI 자원을 포함합니다. iPhone 파일 앱의 HTML 미리보기에서는 JavaScript 실행이 제한될 수 있으며 실제 휴대폰 사용에는 HTTPS 배포가 적합합니다.

[실행·배포 안내](PREVIEW.md) · [공식 자료 접근 상태와 UI 반영 범위](DESIGN.md)

아이콘 원본과 출처는 `assets/icons/`에 있습니다. `python3 build-icons.py`로 원본 무결성을 확인하고 오프라인 이미지 번들을 다시 만들 수 있습니다.

## 이야기 설정

휴대폰 주인은 **양정원**입니다. 설정 프로필에 이름을 표시하며, 캘린더와 홈 위젯에는 **9월 7일 · 지우 생일**이 남아 있습니다. 연도는 지정하지 않아 매년 반복되는 생일로 구성했습니다. 캘린더에서 생일 카드를 누르면 해당 날짜로 이동하고, 이전·다음 달 및 오늘 버튼으로 날짜를 살펴볼 수 있습니다. 설정값은 `app.js`의 `story`에 있습니다.


음악 보관함에는 **오반 — 어떻게 지내**가 등록되어 있습니다. 사용자가 첨부한 MP3 원본과 그 파일의 앨범 커버를 기본으로 포함했습니다. 처음 열면 홈 화면을 먼저 보여주고, 화면이 보이기 시작한 뒤 3초를 기다리고 독의 음악 아이콘에서 음악 앱이 확대되어 열립니다. 직접 다른 앱이나 제어 센터를 열면 자동 전환을 취소합니다. 홈 화면에서는 음원만 미리 불러오고 재생하지 않습니다. 음악 앱이 열리는 순간 자동 재생을 시도하므로 별도 파일 선택이 필요하지 않습니다.

- 자동 재생이 허용되면 음악 앱이 열릴 때 재생을 시작합니다. 브라우저가 소리 자동 재생을 막으면 **소리 켜기** 버튼을 표시합니다. 이 버튼 또는 화면에서 처음 누르는 동작으로 시작합니다. 재생 버튼도 사용할 수 있으며, 일시 정지한 뒤에는 화면을 눌러도 자동으로 다시 시작하지 않습니다.
- 실제 음원 파일에서 길이를 읽으며, 재생·일시 정지·탐색·한 곡 반복·음량 조절이 동작합니다.
- 제어 센터와 웹 잠금 화면에서도 같은 재생 상태를 조작합니다.
- 단일 HTML에는 음원과 앨범 이미지가 모두 포함되므로 실행 중 외부 음악 서버에 접속하지 않습니다.
- `assets/audio/`에 업로드한 MP3 원본, 파일 내 이미지에서 재인코딩 없이 추출한 앨범 커버, 출처·체크섬 매니페스트가 있습니다.
- `python3 build-music.py`는 원본 체크섬을 검증하고 오프라인 번들 `music-assets.js`를 생성합니다. `export.py`도 이 과정을 실행합니다.

### 검증 범위

업로드한 실제 MP3의 전체 디코딩을 확인했습니다. Chromium에서 홈 화면에서 음악 앱으로 자동 전환, 수동 앱 탐색 시 전환 취소, 동작 줄이기 설정, 새 브라우저의 음악 앱 시작, 자동 재생 허용 시 재생, 자동 재생 거절 시 한 번 터치로 시작, 탐색, 제어 센터·웹 잠금 화면 제어 및 오프라인 단일 HTML 재생을 확인했습니다. 실제 iPhone Safari의 자동 재생 허용 여부는 기기·브라우저 설정에 따릅니다.

기존에 로컬 파일을 저장해 두었더라도 이 버전은 기본으로 포함된 곡을 우선 사용합니다. 음원은 프로젝트와 배포 파일에 포함됩니다. 공개 사이트에도 같은 곡이 포함됩니다.

## GitHub Pages 게시

`python3 publish.py`로 `site/still-september/`에 공개용 파일과 MP3·앨범 이미지를 준비합니다. 웹에서는 작은 곡 정보 스크립트와 직접 MP3 주소를 사용해 대용량 음원 스크립트 다운로드를 기다리지 않습니다. HTML의 자원 주소에 내용별 버전을 붙여 오래된 JavaScript 캐시 사용을 막습니다. 배경 탭에서는 홈 화면의 3초를 세지 않고, 뒤로 가기로 페이지가 복원될 때도 홈 화면부터 다시 시작합니다. `site/index.html`은 이 경로로 이동합니다. `.github/workflows/publish.yml`은 `main` 브랜치의 변경 또는 수동 실행으로 사이트를 게시합니다. 저장소의 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.

게시 성공 후 사용할 경로는 `https://dbduddms39-droid.github.io/real/still-september/`입니다. 워크플로 배포 성공과 실제 접속을 확인해야 사용 가능한 주소입니다.

## 사진 갤러리

사진 앱은 3열 사진 목록, **1년 전 오늘** 카드, 원본 비율을 유지한 큰 사진 보기, 이전·다음 버튼과 키보드 탐색을 지원합니다. 추억 날짜는 접속한 날의 1년 전으로 표시하며 윤년의 2월 29일은 전년 2월 28일로 표시합니다.

원본 파일은 `assets/photos/`에 두고 `manifest.json`에 ID·파일 이름·설명·SHA-256을 기록합니다. `memoryPhotoId`는 추억 카드에 사용할 사진의 ID입니다. `python3 build-photos.py`는 원본 체크섬을 검증하고 오프라인 이미지 번들을 만듭니다. 웹 배포는 원본 이미지 파일을 직접 제공하며 주소에 내용별 버전을 붙입니다.

사용자가 제공한 ZIP의 원본 사진 20장을 보관함에 등록했습니다. ‘1년 전 오늘’은 이불을 덮고 자는 사진(`photo-06`)을 사용합니다. 원본 이미지는 수정하지 않고, 갤러리에서는 정사각형 썸네일로, 큰 사진 보기에서는 원본 비율로 표시합니다.
